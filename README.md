# Tin Oxo Studio 5.2.0 — Python / X11 GUI

**v5.2는 Tk/X11 GUI로 실행됩니다.** `python TinOxoStudio.py`를 실행하면 4.0처럼 편집기 창이 열립니다. 기본 실행에는 포트 입력이나 브라우저가 필요하지 않습니다.

## 5.2 리간드 외향 배치

- 코어 원자만의 **질량 가중 무게중심 → 부착 원자** 방향을 기준으로 외향 후보를 탐색합니다. 기존 리간드의 크기나 질량이 기준점을 이동시키지 않습니다. 여러 코어가 있으면 부착점과 연결된 코어를 사용합니다.
- 새 리간드 원자와 내부 결합 경로가 코어의 기하학적 외피 안으로 들어가는 배치는 거부합니다. 코어 원자가 드문 빈 공간을 관통하는 경우도 검사합니다.
- 코어에 붙이는 수동 방향이 무게중심 쪽이면 사유를 표시합니다. L/P 가교는 두 donor 위치를 유지하면서 외부 강체 배치를 찾습니다. 안전한 배치가 없거나 취소하면 기존 리간드·코어 H를 포함한 원본을 복원합니다.
- 코어가 없는 구조는 기존 국소 결합 방향을 사용합니다. 이 규칙은 초기 생성/자동 회전 배치에 적용되며 별도 힘장 최적화의 추가 구속조건은 아닙니다.

## 화면과 도움말

- 계산/검사 설명은 `(?)`에 마우스를 올리거나 클릭하면 표시됩니다. 키보드 Tab 후 Enter도 사용할 수 있습니다. 기본 1600×1000 X11 검사에서 모든 계산 항목이 한 화면에 들어갑니다. 작은 화면이나 큰 글꼴에서는 스크롤을 사용할 수 있습니다.
- 진행률·경과 시간·취소·계산 결과는 **구조 뷰어 바로 위**에 표시합니다. 새 작업을 시작하면 이전 결과 요약을 지웁니다.
- R/L/P 편집 옆 `(?)`는 R=Sn–C, L=카복실레이트, P=포스피네이트와 현재 Sn 위치를 설명합니다. 자리 표 행을 선택하면 해당 Sn과 부착 리간드를 뷰어에 강조합니다.

## 설치와 실행

```bash
conda env create -f environment.yml
conda activate tinoxo
python TinOxoStudio.py
```

기존 환경은 필요한 경우 `conda install -c conda-forge 'tk>=8.6,<9' rdkit ase numpy scipy pillow`로 보완합니다. Tk는 pip로 설치되지 않습니다. 이미 Tk가 있는 환경은 `python -m pip install -r requirements.txt`를 사용할 수 있습니다.

```bash
python TinOxoStudio.py --check
python TinOxoStudio.py examples/Sn12_Methyl.tinoxo.json
```

`--check`는 디스플레이 없이 의존성과 코어를 검사합니다. `--fresh`는 복구 질문 없이 시작하고, `--config-dir DIR`는 설정/복구 폴더를 지정합니다. `--native`는 기본 X11 모드와 같은 호환 옵션입니다.

## MobaXterm / PuTTY / SSH X11

PC에서 X server를 실행하고 SSH 세션의 X11 forwarding을 켠 뒤 다시 접속하세요. PuTTY는 별도의 PC X server가 필요합니다. 서버에서 다음 순서로 확인합니다.

```bash
echo "$DISPLAY"
python -m tkinter
python TinOxoStudio.py
```

Tk 테스트 창이 열리면 닫은 다음 편집기를 실행하세요. SSH가 설정한 `DISPLAY`를 유지하고 임의로 `:0`으로 바꾸지 마세요. `DISPLAY`가 없거나 연결에 실패하면 X11 오류와 안내를 표시합니다. 브라우저로 자동 전환하지 않습니다.

## 계산 범위

계산/검사 탭의 **범위 선택은 ‘선택 범위로 힘장 최적화’와 ‘선택 범위로 겹침 줄이기’에 공통 적용**됩니다.

| 범위 | 고정되는 대상 | 움직일 수 있는 대상 |
|---|---|---|
| 코어만 고정 | 코어의 좌표 | 리간드 원자 |
| 모든 원자 움직이기 | 없음 | 코어와 리간드의 모든 원자 |
| 코어만 움직이기 | 리간드의 좌표 | 코어 원자 |
| 코어·리간드 모양만 고정 | 각 조각의 내부 형태 | 코어에 대한 리간드의 상대 위치·방향 |

위 표는 **‘원자별 고정도 추가 적용’이 꺼진 기본 상태**입니다. 켜면 개별 고정 플래그도 적용합니다. 기존 코어에는 고정 플래그가 있으므로 ‘전체/코어만 움직이기’에서 이 옵션을 켜면 코어가 다시 고정될 수 있습니다. 화면의 고정·이동 원자 수와 선택 버튼으로 실제 대상을 확인할 수 있습니다.

모양 고정 모드는 코어를 기준 좌표계로 유지하고, 코어를 제외한 연결 성분 각각을 강체로 회전·이동합니다. 연결된 가지와 중첩 리간드는 한 강체이며, L/P 다점 가교도 내부 형태를 유지합니다. 내부 거리·결합각·이면각은 강체 변환으로 보존하고 연결부는 조정할 수 있습니다. 개별 고정을 추가 적용하면 고정 원자가 들어 있는 리간드 전체를 고정합니다.

## 힘장과 겹침 줄이기의 차이

| 기능 | 계산 대상 / 결과 |
|---|---|
| 선택 범위로 힘장 최적화 | 전체 구조 MMFF94/UFF 에너지, kcal/mol. 모든 원자·배위 환경의 파라미터가 있어야 실행합니다. |
| 선택 범위로 겹침 줄이기 | 현재 접촉 기준의 겹침 벌점 + 초기 결합/1–3 거리 및 약한 변위 제약. 점수는 임의 단위이며 힘장 에너지가 아닙니다. |
| 리간드 내부만 최적화 | 별도 범위. 코어·부착 경계·개별 고정을 유지하는 H-capped 유기 조각 계산. 위 범위 선택을 적용하지 않습니다. |

**UFF는 표준 Sn3 원자형을 제공합니다.** 5.1부터 Sn 다배위를 일반 유기 원자가 제한으로 먼저 거르던 경로를 수정해 Sn3·Sn6·Sn12 전체 계산을 실행합니다. 계산용 복사본에서 Sn의 엄격한 원자가 검사만 분리하고, 유기 원자의 검사와 원본 그래프·전하·라디칼은 유지합니다.

**MMFF94에는 Sn 원자형이 없습니다.** 기본 켜짐인 ‘MMFF 미지원 시 UFF 사용’을 통해 미지원 전체 모델은 UFF로 계산하며, 진행 상태·결과·프로젝트 메타데이터에 요청/실제 힘장을 기록합니다. 끄면 선택한 힘장만 사용하고 미지원 사유를 표시합니다. 지원되는 유기 구조는 MMFF94를 계속 사용합니다. 리간드 내부 계산도 선택한 MMFF94/UFF를 유지합니다.

UFF의 일반 Sn3 파라미터를 사용한 초기 정리이며 Sn 옥소 클러스터 전용 피팅은 아닙니다. 에너지·구조의 최종 정확성은 별도 검토가 필요합니다. [UFF Sn 원자형 소스](https://github.com/rdkit/rdkit/blob/master/Code/ForceField/UFF/Params.cpp) · [MMFF94 지원 원소 설명](https://openbabel.org/docs/Forcefields/mmff94.html)

최대 반복 수는 1–10000입니다. 결과에 에너지/겹침 점수와 수렴 여부를 표시합니다. 미수렴이어도 개선된 좌표를 적용할 수 있으며, 화면에 미수렴을 명시합니다. 접촉의 깊이를 줄이는 목적함수이므로 접촉 쌍 수가 반드시 줄거나 0이 되는 것은 아닙니다. 실행 취소로 원래 구조를 복원할 수 있습니다.

## 함께 개선된 기능

- `radii`에서는 vdW·공유반경 계수만, `minimum`에서는 공통 최소 거리만 표시·검증합니다. 비활성 방식의 값은 보존합니다.
- XYZ 복사는 현재 모델에서 좌표를 새로 만들고, 일반 입력창은 붙여넣기마다 최신 X11 클립보드를 읽습니다. 선택 텍스트가 CLIPBOARD와 혼동되지 않도록 처리했습니다. PC와 서버 사이의 클립보드 전달은 X server의 연동 설정을 따릅니다.
- 내장 목록의 카복실레이트·포스피네이트 7종은 H가 붙은 중성 산 전구체로 제공합니다. L/P 가교 부착 시 OH를 탈양성자화하는 규칙과 니트로기의 올바른 형식전하는 유지합니다. 저장된 사용자 SMILES를 자동 변환하지 않습니다.
- 전용 진행률 표시줄, %, 경과 시간, 작업 취소 및 계산 결과 요약을 제공합니다. 진행률은 반복 예산·단계·처리 개수 기준이며 남은 시간 예측이 아닙니다. 100%는 작업 완료로, 수렴 여부와 별개입니다.
- 계산 중 중복 실행을 막고, 실패·취소 시 구조와 실행 취소 기록을 보존합니다.

## 저장 / 업데이트

기존 프로그램을 종료한 뒤 **ZIP 전체를 새 폴더에 풀어** 실행하세요. `TinOxoStudio.py`, `TinOxoPlacement.py`, `TinOxoOptimize.py`, `TinOxoWeb.py`, `fonts/` 등 모든 파일을 함께 사용해야 합니다. 창 제목의 **5.2.0 · X11**을 확인하세요.

프로젝트 JSON은 구조·결합·보관함·설정을 보존합니다. X11 모드는 서버의 `~/.config/tinoxo-studio/settings.json` 및 `recovery.json`을 사용합니다. 이전 웹 작업은 웹에서 프로젝트 JSON으로 내보낸 후 X11 GUI에서 불러오세요. 웹 작업 파일을 자동 덮어쓰지 않습니다.

## 선택적 웹 호환 모드

웹 코드도 보존합니다. 사용하려는 경우에만 명시적으로 다음처럼 실행합니다.

```bash
python TinOxoStudio.py --web --port 8888
# 브라우저 자동 열기 없이 서버만 실행
python TinOxoStudio.py --web --port 8888 --no-browser
```

`--port`, `--no-browser`, `--open-browser` 등 웹 옵션에는 `--web`이 필요합니다. 웹 모드에서는 기존 인증·다운로드·자동 저장·브라우저 열기 동작을 유지합니다.
